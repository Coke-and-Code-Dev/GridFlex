Quick start

Use Python 3.11, Node.js LTS and Git. Install the backend from the repository root.

git clone https://github.com/Coke-and-Code-Dev/GridFlex.git
cd GridFlex
python -m venv .venv
source .venv/bin/activate
python -m pip install -r src/requirements.txt

On Windows PowerShell, activate with .venv\Scripts\Activate.ps1.

Download and prepare the datasets, or unpack a prepared archive using the instructions in the README. The full download and build needs about 15 GB of free disk space.

python data/scripts/download_data.py
python data/scripts/setup_data.py build
python data/scripts/setup_data.py status

Start the API from the repository root.

python -m uvicorn api.main:app --app-dir src --reload --port 8000

In a second terminal, start the dashboard and open the URL printed by Vite.

cd ui
npm ci
npm run dev

Interpreting results

  • Fits means the vans receive their planned energy and breaches stay within the selected test tolerance.
  • Fits with risk means the vans receive their planned energy, but more test windows breach the limit than the tolerance allows.
  • Does not fit means at least one van is short of energy.
  • Breach rate is the share of held-out windows with at least one slot over the limit. It describes those windows.

GridFlex is a planning prototype. Confirm available capacity with the grid operator before acting. Battery replay uses the planned battery actions. AI explanations are grounded in computed evidence and should be checked against the results.

Read two numbers together

Start with unmet energy (kWh) and windows over the limit (%). The first tells you whether the vans got enough charge. The second tells you how often the building and fleet together exceeded the site limit in testing. Then use the van heatmap or breach timing chart to see where the problem occurs.

Troubleshooting

The dashboard cannot reach the API
Start the backend and wait for it to finish starting. The dashboard defaults to http://127.0.0.1:8000. Set VITE_GRIDFLEX_API_URL if you use another API address.
The sector profiles are missing
Run python data/scripts/setup_data.py status from the repository root to check which prepared data files are available.
Reality Check has no comparison
The graph needs a GLASS profile and a matching Liander reference. A run using the depot's own meter file skips this comparison.
