Quick start

Use Python 3.11, Node.js LTS and Git. Install the backend from the repository root.

git clone https://github.com/Coke-and-Code-Dev/GridFlex.git
cd GridFlex
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

On Windows PowerShell, activate with .venv\Scripts\Activate.ps1.

Download and prepare the datasets, or unpack a prepared archive using the instructions in the README. The full download and build needs about 15 GB of free disk space.

python scripts/download_data.py
python scripts/setup_data.py build
python scripts/setup_data.py status

Start the API from the repository root.

python -m uvicorn api.main:app --reload --port 8000

In a second terminal, start the dashboard and open the URL printed by Vite.

cd ui
npm ci
npm run dev

Interpreting results

  • Fits means the vans receive their planned energy and breaches stay within the selected test tolerance.
  • Fits with risk means the vans receive their planned energy, but more test windows breach the limit than the tolerance allows.
  • Does not fit means at least one van is short of energy.
  • Breach rate is the share of held-out windows with at least one slot over the limit. It describes those windows.

GridFlex is a planning prototype. Confirm available capacity with the grid operator before acting. Battery replay uses the planned battery actions. AI explanations are grounded in computed evidence and should be checked against the results.
